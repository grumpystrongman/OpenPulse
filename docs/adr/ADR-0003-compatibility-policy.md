# ADR-0003: Compatibility Policy

Date: 2026-04-02

## Decision
Enforce backward compatibility for all minor versions and require governance approval for breaking changes.

## Rationale
- Manufacturer and provider adoption depends on predictable interfaces.
- Breaking changes create high integration costs.

## Consequences
- Release process includes migration checks and conformance suites.
- `openpulse-governor-jeff` approval required for major changes.
