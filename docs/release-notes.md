# Release Notes v0.1.0-rc1

- Introduced OpenPulse v1 canonical schema, taxonomy, and compatibility policy.
- Implemented ingestion gateway with idempotency and rate limiting.
- Implemented connector service with realistic synthetic feeds for 8 required ecosystems.
- Implemented normalization worker with provenance, quality scoring, and domain table materialization.
- Implemented query API, consent identity service, EHR export service, governance engine, and ops console.
- Added Docker Compose local stack with ClickHouse, Redpanda, MinIO, Redis, Prometheus, Grafana.
- Added conformance, integration, and scenario test suites.
